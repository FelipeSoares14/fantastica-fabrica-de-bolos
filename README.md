# A Fantástica Fábrica de Bolos

Site de encomendas de bolos caseiros, pudins e cafés em Pindamonhangaba e Taubaté. O cliente monta o pedido no site e confirma pelo WhatsApp.

- `index.html`: o site
- `img/`: fotos dos produtos

O material de pesquisa (conversas e áudios) fica no OneDrive e não entra aqui.

## Como abrir

Abra o `index.html` no navegador.
